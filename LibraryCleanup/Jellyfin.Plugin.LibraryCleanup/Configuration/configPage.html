Library Cleanup

Find and repair common Jellyfin season and episode database/metadata mistakes.
Conservative first build. Safe Repair only realigns stale episode SeasonId, SeriesId, and season-number links to the episode's physical folder hierarchy, then queues a normal Jellyfin refresh. The plugin does not delete, move, rename, or recycle media files. Duplicate database records are diagnosed but are not automatically purged in v0.1.
